# Quick start and demonstration talking points

Start with `docker compose up --build`, open http://localhost:8000, and keep the console on a 1920×1080 screen.

## The one-sentence pitch

"NEXUS treats users, devices, network, services, configuration, policy, risk and incidents as one continuously
reconciled system - it doesn't just tell you something broke, it works out why, who is affected, whether it can
safely fix it, and proves the fix worked."

## Acts

1. **Healthy baseline (Overview).** Point at the instrument strip, the health distribution and the loop strip in the
   top bar: "every phase lights up as real events arrive". Mention the history: "the past week was generated by the
   real engines on a shifted clock - including a failed fix that rolled back".
2. **Digital twin.** Select LINUX01. "The topology and the dependencies are live state, not a drawing. The portal
   depends on Nginx, AD DS and PostgreSQL - that graph drives correlation and recovery order."
3. **Identity.** Eldar's chain. "IP addresses don't identify people. Identity confidence corroborates AD, DHCP, DNS,
   MAC and VLAN - and it's labelled as a configurable heuristic, not magic."
4. **Access.** Explain Eldar → LINUX01:22 then Aysel → LINUX01:22. "Same evaluator for leases and explanations, so the
   explanation can't drift from the decision." If it's after 18:00, show the approval requirement.
5. **Service failure (Chaos lab → Kill Nginx).** "Chaos only breaks the simulated host. Detection, triage, decision,
   restart and verification are NEXUS. Note the verification: systemd active, TCP/443 open, HTTP 200 - not the exit code."
6. **Configuration drift (Break SSH config).** Drift page: desired vs actual, real diff, checksum mismatch. "It's a
   REVERSIBLE action at 91% confidence, so it runs - backup first, sshd -t, reload, verify, rollback available."
7. **Unknown device.** "No AD object, unknown MAC, no DNS. Then it tries SSH. Risk crosses 80, SECURITY-004 allows
   automatic quarantine for unmanaged endpoints only - a managed server would need approval."
8. **Time machine and what-if.** Rewind to before the quarantine; simulate VLAN 30 failing. "Read-only: nothing changed."
9. **Blackout.** Nine faults at once. "Watch the DNS alert storm collapse into one incident, EMERGENCY mode, dependency
   order, and the policy conflict left for a human on purpose." Open the final report.
10. **Close with Fail remediation** (optional). "A bad deploy plus a hidden host firewall rule: the restart exits 0,
    verification fails, NEXUS rolls back and escalates instead of declaring success."

## If something goes wrong on stage

- Use the presentation panel's **Reset**, or System → Reset demo environment (about 5 seconds).
- The **Live** indicator turns amber if the WebSocket drops; it reconnects automatically.
